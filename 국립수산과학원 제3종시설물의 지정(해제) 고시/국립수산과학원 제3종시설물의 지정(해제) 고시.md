# (해양수산부) 제3종 시설물의 지정고시
> 고시 · 행정규칙 · 시행 2018-07-18 · 공포 2018-07-12 · 제정

### 전문
특정관리대상시설을 포함하여 중앙행정기관이 제3종시설물 범위 중 재난발생의 위험이 있거나 계속적 안전관리가 필요한 시설물을 제3종시설물로 지정하여 고시 합니다 제3종 시설물의 지정고시![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=35593869)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=35593870)
