# 항로표지 장비·용품 검사수수료
> 고시 · 행정규칙 · 시행 2013-04-15 · 공포 2013-04-15 · 제정

### 전문
◎ 소형급 등명기 검사수수료(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851035)1) 색도검사와 수직·수평발산각검사는 점멸식인 경우 검사수수료이며 회전식인 경우 1면당 검사 시 소요 검사수수료입니다.2) 등질검사와 유효광도검사의 경우 1종류 검사 시 소요 검사수수료입니다.3) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다. ◎ 소형급 등명기 내환경 검사수수료(신설)(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851036)1) 검사기본료는 기존의 등명기 검사기본료(51,100원, 부가세포함)를 적용합니다.2) 내환경 검사를 광학적, 전기적특성 검사와 병행하여 신청할 경우에는 검사기본료는 이중으로 부과하지 않습니다.3) 내환경 검사는 표본검사(검사대상 수량의 5% / 20대 미만은 1대) 방법으로 실시합니다. ◎ 중형급(점멸식) 등명기 검사수수료(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851040)1) 등질검사와 유효광도검사의 경우 1종류 검사 시 소요 검사수수료입니다.2) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다. ◎ 중형급(회전식) 등명기 검사수수료(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851069)1) 색도검사와 수직·수평발산각검사는 1면당 검사시 소요 검사수수료입니다.2) 등질검사와 유효광도검사의 경우 1종류 검사 시 소요 검사수수료입니다.3) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다. ◎ 대형급 등명기 검사수수료(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851041)1) 색도검사와 수직·수평발산각검사는 1면당 검사 시 소요 검사수수료입니다.2) 등질검사와 유효광도검사의 경우 1종류 검사시 소요 검사수수료입니다.3) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다. ◎ 충방전조절기 검사수수료(신설)(단위:원/1대당 검사료)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13851070)1) 검사 기본료는 기존 등명기 검사 기본료(51,100원, 부가세포함)를 적용합니다.2) 내환경 검사를 전기적 특성 검사와 병행하여 신청할 경우 검사 기본료는 이중으로 부과하지 않습니다.3) 내환경 검사는 표본검사(검사대상 수량의 10% / 10대 미만은 1대) 방법으로 실시합니다.
