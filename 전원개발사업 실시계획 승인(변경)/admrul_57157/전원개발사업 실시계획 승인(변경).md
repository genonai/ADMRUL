# 전원개발사업 실시계획 승인(변경)
> 고시 · 행정규칙 · 시행 2017-04-10 · 공포 2017-04-10 · 일부개정

### 전문
154kV 강화-서강화 송전선로 건설사업(변경)1. 사업의 명칭 : 154kV 강화-서강화 송전선로 건설사업 2. 사업시행자의 성명 및 주소 : 한국전력공사 사장 조 환 익전라남도 나주시 전력로 55 (빛가람동) 3. 변경사유가. 장기송배전설비계획 변경('17.10 → '18.12)나. 지역주민과의 합의 및 인·허가 지연에 따른 사업기간 변경 (복구기간 반영) 4. 변경내역가. 사업시행 기간![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770708)나. 기타 변경사항 없음 154kV 신온양-한샘 경과지 변경 송전선로 건설사업(변경)1. 사업의 명칭 : 154kV 신온양-한샘 경과지 변경 송전선로 건설사업 2. 사업시행자의 성명 및 주소 : 한국전력공사 사장 조 환 익전라남도 나주시 전력로 55 (빛가람동) 3. 변경사유가. 송전선로 지중화 요청에 따른 경과지 확정지연나. 가압목표 변경('17. 4 → '18.10)에 따른 사업기간 변경(복구기간 반영) 4. 변경내역가. 사업시행 기간![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770709)나.  기타 변경사항 없음 154kV 산하변전소 및 관련 송전선로 건설사업(변경)1. 사업의 명칭 : 154kV 산하변전소 및 관련 송전선로 건설사업 2. 사업시행자의 성명 및 주소 : 한국전력공사 사장 조 환 익전라남도 나주시 전력로 55 (빛가람동) 3. 변경사유가. 장기송배전설비계획 변경('17.06 → '19.06)나. 울산 강동권 개발사업 지연으로 전원공급시기 변경나. 154kV 모선구분차단기 설치기준 변경에 의한 전원설비 사양 변경 (복구 및 설치기간 반영) 4. 변경내역가. 사업시행 기간![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770760)나. 전원설비 사양![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770761)다. 기타 변경사항 없음 345kV 창원변전소 건설사업(변경)1. 사업의 명칭 : 345kV 창원변전소 건설사업 2. 사업시행자의 성명 및 주소 : 한국전력공사 사장 조 환 익전라남도 나주시 전력로 55 (빛가람동) 3. 변경사유가. 장기송배전설비계획 변경('16.11 → '17.11)나. 지역주민과의 합의지연으로 사업기간 부족 4. 변경내역가. 사업시행 기간![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770823)나.  기타 변경사항 없음 강릉안인화력 1,2호기 건설사업(변경)1. 사업의 명칭 : 강릉안인화력 1,2호기 건설사업 2. 사업시행자의 성명 및 주소 : 강릉에코파워 주식회사 사장 엄 창 준강원도 강릉시 교동 하슬라로 184 3. 변경사유가. 토지 권리설정사항 변경 : 가압류 둥기말소, 근저당권설정 등기말소, 지상권설정 등기말소나. 토지 소유자 변경 : 증여에 의한 소유자 변경다. 토지 지번 변경 : 분할측량에 의한 지적분할 4. 변경내역가. 변경할 토지 명세서(1) 발전시설 용지조서![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770762)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770764)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770766)(2) 도로시설 용지조서![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770819)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770820)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=29770821)나.  기타 변경사항 없음
