# 국가지정문화재 주변 현상변경 허용기준

### 전문
1. 고 시 명 : 국가지정문화재 주변 현상변경 허용기준 2. 고시내용가. 대상문화재![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13164454)나. 관련근거ㅇ 문화재보호법 제15조, 제34조, 제90조ㅇ 문화재보호법 시행령 제5조, 제23조, 제52조ㅇ 문화재보호법 시행규칙 제30조 제2항 및 제3항, 제79조다. 기준의 적용ㅇ 본 허용 기준은 「문화재보호법 시행규칙」제30조 제2항 제1호 가, 제79조 제6항 행위를 대상으로 한정하며, 그 이외의 사항에 대하여는 현행과 같은 절차에 따라 처리함.ㅇ 본 허용기준 이하의 행위는 「문화재보호법」제90조 제2항 및 동 법 시행규칙 제79조 제1항 및 제6항에 의거 문화재 보존에 영향을 미칠 우려가 없는 행위로 문화재 영향검토를 생략하고, 지방자치단체에서 자체 처리함.라. 현상변경 허용 기준ㅇ 문화재별 현상변경허용기준 : 세부내용 별첨ㅇ 현상변경 허용기준 도면- 문화재청 홈페이지(www.cha.go.kr) : 정보광장-법령정보-훈령?예고?고시 참조 3. 기준 시행일 : 관보 고시일 4. 연 락 처가. 문화재청 천연기념물과ㅇ 주 소 : (우)302-701 대전광역시 서구 둔산동 920번지 정부대전청사 1동ㅇ 연락처 : 전화 (042)481-4989～4991, 전자메일 lavaecho@korea.kr나. 지방자치단체ㅇ 경상북도 문화재과 : 전화 (053)950-3579, 전송 (053)950-3349ㅇ 의성군 새마을문화과 : 전화 (054)830-6549, 전송 (054)830-6099ㅇ 전라남도 문화예술과 : 전화 (061)286-5445, 전송 (061)286-4772ㅇ 해남군 문화관광과 : 전화 (061)530-5856, 전송 (061)530-5598ㅇ 목포시 문화예술과 : 전화 (061)270-8155, 8320 전송 (061)270-3577ㅇ 충청남도 문화예술과 : 전화 (042)251-2278, 전송 (042)251-2279ㅇ 태안군 문화관광과 : 전화 (041)670-2571, 전송 (041)670-2226 ![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13164475)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=13164476)
