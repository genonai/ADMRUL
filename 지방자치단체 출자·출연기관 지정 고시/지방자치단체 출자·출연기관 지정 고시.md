# 2020년 3분기 지방자치단체 출자·출연기관 지정 고시
> 고시 · 행정규칙 · 시행 2020-08-10 · 공포 2020-08-10 · 전부개정

### 전문
1. 신규지정 15(출자기관 2, 출연기관 13)○ 출자기관주식회사 강원수출, 군산시민발전 주식회사○ 출연기관재단법인 광진복지재단, 재단법인 부산진문화재단, 재단법인 광주광역시 사회서비스원, 재단법인 대전과학산업진흥원, 재단법인 울산일자리재단, 재단법인 강원도일자리재단, 재단법인 춘천시 마을자치지원센터, 재단법인 청양군 지역활성화재단, 재단법인 군산시상권활성화재단, 재단법인 곡성군미래교육재단, 재단법인 경상남도 관광재단, 재단법인 경상남도 여성가족재단, 재단법인 사천시 친환경미생물발효연구재단 2. 지정해제 3(출자기관 2, 출연기관 1)○ 출자기관양주역세권개발자산관리주식회사, 증평이산업단지개발 주식회사○ 출연기관재단법인 충주당뇨바이오진흥재단 3. 변경지정 9(출연기관 9)○ 출연기관재단법인 부산디자인진흥원, 재단법인 인천광역시계양구 인재양성교육재단, 재단법인 광주광역시 여성가족재단, 재단법인 광주디자인진흥원, 재단법인 대전디자인진흥원, 재단법인 서구인재육성재단, 재단법인 울산연구원, 재단법인 백제문화제재단, 재단법인 전라북도인재평생교육진흥원
