# 2017년도 지방자치단체 출자·출연 기관 지정 고시
> 고시 · 행정규칙 · 시행 2017-07-31 · 공포 2017-07-31 · 일부개정

### 전문
1. 신규 지정 14(출자기관 4, 출연기관 10)ㅇ 출자기관성동미래일자리(주), 의정부리듬시티(주),             의정부리듬시티자산관리(주), 완주농공단지개발(주)ㅇ 출연기관120다산콜재단, 서울특별시공공보건의료재단, 은평문화재단, 광주서구장학재단, 대전효문화진흥원, 광명문화재단, 고양시정연구원, 철원장학회, 영동축제관광재단, 충주당뇨바이오진흥재단,  2. 명칭 변경 8(출자기관 1, 출연기관 7)ㅇ 출자기관농업회사법인 임실고추앤농산물가공판매(주)  (구. 농업회사법인 전북동부권고추)ㅇ 출연기관인천글로벌캠퍼스운영재단     (구. 송도글로벌캠퍼스운영재단)오산시창의인재육성재단       (구. 오산시애향장학회)경기농식품유통진흥원         (구. 경기농림진흥재단)충청북도기업진흥원           (구. 충청북도지방기업진흥원)김해산업진흥의생명융합재단   (구. 김해시차세대의생명융합산업지원센터)제주평생교육장학진흥원       (구. 제주국제화장학재단)제주연구원                   (구. 제주발전연구원)  3. 지도·감독기관 변경 1(출연기관 1)ㅇ 광주전남연구원(전라남도 → 광주광역시)  4. 지정 해제 2(출연기관 2)ㅇ 강화고려역사재단(인천문화재단과 통합)ㅇ 남도장학회(광주광역시로 지도·감독기관 일원화)
