# 통계작성의 승인 고시(울산광역시구군단위장래인구추계)
> 고시 · 행정규칙 · 시행 2017-11-20 · 공포 2017-11-20 · 제정

### 전문
1. 통계의 명칭 : 울산광역시구군단위장래인구추계 2. 통계작성기관의 명칭 : 울산광역시 3. 통계작성승인번호(작성승인일) : 제207008호(2017.11.16.) 4. 통계작성의 목적 : 울산광역시의 출생, 사망, 이동 등 인구변동자료를 이용하여 구군별 장래인구를 추계하고, 중장기 지역정책 기초자료로 활용하기 위함 5. 통계작성의 대상 : 구군별 추계인구 관련항목 6. 통계작성의 주기  : 5년 7. 통계작성의 방법  : 가공통계/일반통계
