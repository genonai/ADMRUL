# 통계작성의 변경승인 고시(방송산업실태조사)

### 전문
1. 통계의 명칭 : 방송산업실태조사 2. 통계작성기관의 명칭 : 과학기술정보통신부, 방송통신위원회 3. 통계작성승인번호(작성승인일) : 제920010호(2006. 04. 11.) 4. 통계작성의 변경 연월일 : 2018. 04. 09. 5. 통계작성의 변경 내용과 사유 : 조사항목 변경
