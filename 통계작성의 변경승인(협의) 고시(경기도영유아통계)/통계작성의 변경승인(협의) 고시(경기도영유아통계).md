# 통계작성의 승인 고시(경기도영유아통계)
> 고시 · 행정규칙 · 시행 2018-11-25 · 공포 2018-11-19 · 제정

### 전문
1. 통계의 명칭 : 경기도영유아통계 2. 통계작성기관의 명칭 : 경기도 3. 통계작성승인번호(작성승인일) : 제210010호(2018. 11. 14.) 4. 통계작성의 목적 : 경기도 영유아관련 특성(인구, 보건, 사회적)을 행정자료 기반으로 종합적으로 파악하여 저출산 및 보육정책 수립의 기초자료로 활용하기 위함 5. 통계작성의 대상 : 경기도 주민등록인구 중 영유아인구(만 0~5세) 6. 통계작성의 주기  : 3년 7. 통계작성의 방법  : 가공통계/일반통계
