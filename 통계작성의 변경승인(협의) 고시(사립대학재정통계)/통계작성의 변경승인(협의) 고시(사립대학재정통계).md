# 통계작성의 변경승인 고시(사립대학재정통계)
> 고시 · 행정규칙 · 시행 2017-12-04 · 공포 2017-12-04 · 일부개정

### 전문
1. 통계의 명칭 : 사립대학재정통계 2. 통계작성기관의 명칭 : 한국사학진흥재단 3. 통계작성승인번호(작성승인일) : 제418001호(2013. 11. 11.) 4. 통계작성의 변경 연월일 : 2017.11.30. 5. 통계작성의 변경 내용과 사유 : 결과표 변경 (법령개정사항 반영, 이용자편의 제고)
