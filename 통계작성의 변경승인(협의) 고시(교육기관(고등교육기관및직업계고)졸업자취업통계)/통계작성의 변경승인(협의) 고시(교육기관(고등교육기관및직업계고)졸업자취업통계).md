# 통계작성의 변경승인(협의) 고시(교육기관(고등교육기관및직업계고)졸업자취업통계)
> 고시 · 행정규칙 · 시행 2021-01-04 · 공포 2020-12-29 · 일부개정

### 전문
1. 통계의 명칭 : 교육기관(고등교육기관및직업계고)졸업자취업통계 2. 통계작성기관의 명칭 : 한국교육개발원, 통계청 3. 통계작성승인(협의)번호 [작성승인(협의)일]: 제920024호 [2004.03.30.]※ 공동작성통계로 승인번호 변경(2020.9.3.) 4. 통계작성의 변경 연월일 : 2020. 12. 22. 5. 통계작성의 변경 내용과 사유 :![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=92814393)* 일자리이동통계(제101091호), 통계청 기업체(사업체) 통계 작성 시 ‘통계표준용어’로 변경
