# 통계작성의 변경승인(협의) 고시(인천광역시중구기본통계)
> 고시 · 행정규칙 · 시행 2025-02-14 · 공포 2025-02-20 · 일부개정

### 전문
1. 통계의 명칭: 인천광역시중구기본통계 2. 통계작성기관의 명칭: 인천광역시 중구 3. 통계작성승인(협의)번호 [작성승인(협의)일]: 제561001호 [2007.04.23.] 4. 통계작성의 변경 연월일: 2025.02.14. 5. 통계작성의 변경 내용과 사유: 세부내역 붙임참조(통계표 추가1개, 변경 4개)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=149551735)
