# 2011년 폐기물 분야 온실가스·에너지 관리업체 지정
> 고시 · 행정규칙 · 시행 2011-07-29 · 공포 2011-07-29 · 제정

### 전문
![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=6356264)□ 이의신청ㅇ 관리업체 지정·고시에 이의가 있는 관리업체는 고시된 날부터 30일 이내에 「온실가스·에너지 목표관리 운영 등에 관한 지침」(환경부 고시 제2011-29호, 2011.3.16)
제21조(별지 제4호 서식)에 따라 소명자료를 작성하여 환경부에 이의를 신청할 수 있음
