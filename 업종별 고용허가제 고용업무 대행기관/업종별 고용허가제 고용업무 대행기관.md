# 업종별 고용허가제 민간업무 대행기관
> 고시 · 행정규칙 · 시행 2010-12-30 · 공포 2010-12-30 · 폐지제정

### 전문
1. 제조업 분야가. 기관명(지정번호) : 중소기업중앙회(제2010-10호)나. 소재지 : 서울시 영등포구 여의도동 16-2다. 대표자 : 김 기 문라. 업무범위○ 업종 : 제조업, 재생용 재료수집 및 판매업, 건설폐기물처리업○ 업무범위 : 외고법 제27조의2 제1항 각 호에서 규정한 업무마. 지정기간 : 변경 고시일 부터 2013년 11월 8일 까지2. 농축산업 분야가. 기관명(지정번호) : 농업협동조합중앙회(제2010-11호)나. 소재지 : 서울시 중구 충정로 1가 75번지다. 대표자 : 최 원 병라. 업무범위○ 업종 : 농?축산업○ 업무범위 : 외고법 제27조의2 제1항 각 호에서 규정한 업무마. 지정기간 : 변경 고시일부터  2013년 11월 8일까지3. 어업 분야 민간가. 기관명(지정번호) : 수산업협동조합중앙회(제2010-12호)나. 소재지 : 서울시 송파구 신천동 11-6다. 대표자 : 이 종 구라. 업무범위○ 업종 : 어업(소금채취업 포함), 냉장?냉동 창고업○ 업무범위 : 외고법 제27조의2 제1항 각 호에서 규정한 업무마. 지정기간 : 변경 고시일부터 2013년 11월 8일 까지4. 건설업 분야가. 기관 명(지정번호) : 대한건설협회(제2010-13호)나. 소재지 : 서울시 강남구 논현동 71-2다. 대표자 : 권 홍 사라. 업무범위○ 업종 : 건설업○ 업무범위 : 외고법 제27조의2 제1항 각 호에서 규정한 업무마. 지정기간 : 변경 고시일부터 2013년 11월 8일까지

## 부칙
### 부칙 (공포 2010-12-30 제2010-54호)
부칙 <제2010-54호,2010. 12. 30.>① (시행일) 이 고시는 고시한 날로부터 시행한다.② (다른 고시의 폐지) 노동부고시 제2010-21호(2010. 11. 8.)는 이 고시 시행과 동시에 이를 폐지한다.
