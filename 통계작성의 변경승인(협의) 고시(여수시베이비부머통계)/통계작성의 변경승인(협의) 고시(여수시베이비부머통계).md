# 통계작성의 작성승인 고시(여수시베이비부머통계)
> 고시 · 행정규칙 · 시행 2016-07-18 · 공포 2016-07-18 · 제정

### 전문
1. 통계의 명칭 :  여수시베이비부머통계 2. 통계작성기관의 명칭 : 전라남도 여수시 3. 통계작성승인번호(작성승인일) : 제73203호(2016. 07. 11.) 4. 통계작성의 목적 : 여수시 ‘베이비부머’ 의 삶의 질 향상을 위한 노령화 정책 수립의 기초자료 제공 5. 통계작성의 대상 : 개인 6. 통계작성의 주기 : 3년 7. 통계작성의 방법 : 가공통계
