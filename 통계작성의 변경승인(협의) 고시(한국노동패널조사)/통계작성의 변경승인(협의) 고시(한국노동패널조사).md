# 통계작성의 변경승인 고시(한국노동패널조사)
> 고시 · 행정규칙 · 시행 2017-03-27 · 공포 2017-03-27 · 일부개정

### 전문
1. 통계의 명칭 : 한국노동패널조사 2. 통계작성기관의 명칭 : 한국노동연구원 3. 통계작성승인번호(작성승인일) : 제336001호(1998. 12. 21.) 4. 통계작성의 변경 연월일 : 2017. 03. 20. 5. 통계작성의 변경 내용과 사유 :① 취업자, 미취업자 신규조사자 설문: 행복관련 문항 추가(3항목)② 청년용 부가조사 삭제 (작성주기 미도래)
