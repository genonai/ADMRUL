# 통계작성의 작성승인 고시(서울특별시자치구별장래인구추계)
> 고시 · 행정규칙 · 시행 2016-02-01 · 공포 2016-02-01 · 제정

### 전문
1. 통계의 명칭 : 서울특별시자치구별장래인구추계 2. 통계작성기관의 명칭 : 서울특별시 3. 통계작성승인번호(작성승인일) : 제20114호(2016. 01. 28.) 4. 통계작성의 목적 : 인구변동의 실적자료를 이용하여 자치구별 과거인구를 확정하고, 장래인구를 추계하여 중장기 지역정책 기초자료 제공 5. 통계작성의 대상 : 2013~2033년 서울특별시 25개 자치구별 상주인구(외국인 포함) 6. 통계작성의 주기  : 5년 7. 통계작성의 방법  : 가공통계
