# 통계작성의 변경승인(협의) 고시(사회조사)
> 고시 · 행정규칙 · 시행 2022-05-02 · 공포 2022-04-26 · 일부개정

### 전문
1. 통계의 명칭 : 사회조사 2. 통계작성기관의 명칭 : 통계청 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제101018호 [1977.03.17.] 4. 통계작성의 변경 연월일 : 2022.04.18. 5. 통계작성의 변경 내용과 사유 :![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=115242343)※ 사회조사는 2년 주기로 동일 부문을 작성하고 있어 ‘20년 실시한 조사 내용과 변경사항을 비교하였고, 단순문구 수정 및 순서변경 사항은 변경 내역에서 제외함
