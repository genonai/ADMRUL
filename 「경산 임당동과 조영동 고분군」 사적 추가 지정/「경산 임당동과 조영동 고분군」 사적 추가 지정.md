# 경산 임당동과 조영동 고분군 사적 추가 지정
> 고시 · 행정규칙 · 시행 2017-07-03 · 공포 2017-07-03 · 제정

### 전문
1. 고 시 명 : 「경산 임당동과 조영동 고분군」 사적 추가 지정 2. 고시내용가. 대상문화재 : 사적 제516호「경산 임당동과 조영동 고분군」ㅇ 소재지 : 경북 경산시 임당동 676-1 등나. 문화재구역 추가지정 면적ㅇ 6필지 2,351㎡ (경상북도 경산시 압량면 부적리 379, 379-4, 379-5, 379-6, 380, 397-4번지)다. 추가지정 사유ㅇ 발굴조사 결과 임당유적과 성격이 같은 고분과 유구 및 유물이 확인되었으며, 특히 임당유적에서 최초로 확인된 제의와 관련된 것으로 추정되는 적석유구는 신라에 편입된 과거 압독국 유력 세력의 5~6세기 상장례 연구에 귀중한 자료로 역사적·학술적 가치가 높으므로 사적으로 지정하여 관리하고자 함 3. 추가 지정일 : 관보 고시일 4. 특기사항가. 「토지이용계획 기본법」
제8조(지역·지구등의 지정 등)에 따른 지형도면 등은 ‘문화재공간정보(GIS)서비스(http://www.gis-heritage.go.kr) 알림마당-지형도면고시’에서 열람이 가능합니다. 5. 연 락 처가. 문화재청ㅇ 문화재청 보존정책과 : 전화 042-481-4842/팩스 042-481-4849- 주    소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 경상북도 문화유산과 : 전화 054-880-3168 / 팩스 054-880-3179- 주    소 : (우 36759) 경상북도 안동시 풍천면 도청대로 455- 홈페이지 : http://www.gb.go.krㅇ 경산시 문화관광과 : 전화 054-810-5370 /팩스 054-810-6099- 주    소 : (우 38617) 경상북도 경산시 남매로 159- 홈페이지 : http://www.gbgs.go.kr
