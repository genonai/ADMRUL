# 덕유산국립공원계획 변경
> 고시 · 행정규칙 · 시행 2020-07-08 · 공포 2020-07-02 · 일부개정

### 전문
1. 공원의 명칭 및 종류 : 덕유산국립공원 2. 공원구역의 면적 : 229.430㎢ 3. 주요보호대상 자원 : 변경 없음 4. 용도지구계획 : 변경 없음 5. 공원시설계획 변경 조서가. 총괄                                                                  (단위 : 개소)  ![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=94122281)나. 금회 변경되는 공원시설 개요1) 교통·운수시설▨ 탐방로![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=94122229)<공원계획 변경 조건>- 관계기관 협의 의견 및 자연환경 영향 검토결과를 준수- 야생생물 보호 대책을 수립·시행 6. 기존시설의 존치·이전·철거·개수계획 : 변경 없음 7. 공원관리계획 : 변경 없음 8. 공원계획 변경도 : 도면생략 9. 기타 : 관계도서를 국립공원공단 덕유산국립공원사무소(063-322-4174)에 비치하여 일반인 및 이해관계인에게 보입니다.
