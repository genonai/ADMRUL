# 통계작성의 승인 고시(광주시노인복지통계)
> 고시 · 행정규칙 · 시행 2017-09-25 · 공포 2017-09-25 · 제정

### 전문
1. 통계의 명칭 : 광주시노인복지통계 2. 통계작성기관의 명칭 : 경기도 광주시 3. 통계작성승인번호(작성승인일) : 제637003호(2017.09.19.) 4. 통계작성의 목적 : 광주시 노인(65세 이상)의 경제·사회적 삶의 수준 등 노인의 삶을 다차원적으로 분석하여, 삶의 질 향상을 위한 노인복지정책 수립의 기초자료로 활용 5. 통계작성의 대상 : 개인 6. 통계작성의 주기 : 2년 7. 통계작성의 방법 : 가공통계
