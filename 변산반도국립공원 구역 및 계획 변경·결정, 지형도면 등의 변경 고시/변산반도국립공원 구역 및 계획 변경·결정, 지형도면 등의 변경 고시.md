# 변산반도국립공원계획 변경
> 고시 · 행정규칙 · 시행 2020-05-13 · 공포 2020-05-07 · 일부개정

### 전문
1. 공원의 명칭 및 종류 : 변산반도국립공원 2. 공원구역의 면적 : 153.934㎢ 3. 주요보호대상 자원 : 변경 없음 4. 용도지구계획 : 변경 없음 5. 공원시설계획 변경 조서가. 총괄(단위: 개소)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=94120833)나. 금회 변경되는 공원시설 개요5) 문화시설■ 자연학습장![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=94120849)< 공원계획 변경 조건 >- 관계기관 협의 의견 및 자연환경 영향 검토결과 조치계획을 준수할 것- 조경 식재 시 변산반도국립공원 자생수종을 이용할 것- 훼손이 불가피한 수목은 생태성과 경관성을 고려하여 이식계획을 수립·시행할 것- 주변지역의 생태·역사·문화자원과 연계한 체험프로그램을 개발·운영할 것 6. 기존시설의 존치·이전·철거·개수계획 : 변경 없음 7. 공원관리계획 : 변경 없음 8. 공원계획 변경도 : 도면생략 9. 기타 : 관계도서를 국립공원공단 변산반도국립공원사무소(063-582-7808)에 비치하여 일반인 및 이해관계인에게 보입니다.
