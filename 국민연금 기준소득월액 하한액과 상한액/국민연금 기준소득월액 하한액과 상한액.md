# 국민연금 기준소득월액 하한액과 상한액
> 고시 · 행정규칙 · 시행 2015-07-01 · 공포 2015-03-27 · 일부개정

### 전문
1. 국민연금 기준소득월액가. 하한액 : 270천원나. 상한액 : 4,210천원 2. 적용기간 : 2015년도 7월분부터 2016년도 6월분까지
