# 국민연금 기준소득월액 하한액과 상한액
> 고시 · 행정규칙 · 시행 2013-03-26 · 공포 2013-03-26 · 일부개정

### 전문
1. 국민연금 기준소득월액가. 하한액 : 250천원나. 상한액 : 3,980천원 2. 적용기간 : 2013년도 7월분부터 2014년도 6월분까지

## 부칙
### 부칙 (공포 2013-03-26 제2013-47호)
