# 통계작성의 승인(협의) 고시(당진시1인가구실태조사)
> 고시 · 행정규칙 · 시행 2022-07-11 · 공포 2022-07-05 · 제정

### 전문
1. 통계의 명칭 : 당진시1인가구실태조사 2. 통계작성기관의 명칭 : 충청남도 당진시 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제705005호 [2022.06.27.] 4. 통계작성의 목적 : 1인가구의 생활실태를 파악하여  관련정책 수립을 지원하고자 함. 5. 통계작성의 대상- 대상 : 가구/가구- 대상 범위 및 규모 : 조사기준시점 당진시 거주 만 18세이상 1인가구- 대상지역 : 동읍면 6. 통계작성의 주기 : 3년 7. 통계작성의 방법 : 조사통계/일반통계
