# 통계작성의 승인(협의) 고시(산업디지털전환실태조사)
> 고시 · 행정규칙 · 시행 2024-07-24 · 공포 2024-08-01 · 제정

### 전문
1. 통계의 명칭 : 산업디지털전환실태조사 2. 통계작성기관의 명칭 : 산업통상자원부 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제115039호 [2024.07.24.] 4. 통계작성의 목적 : 「산업디지털전환 촉진법」 제6조 5. 통계작성의 대상- 대상 : 사업체/사업체- 모집단 : 2022년 기준 전국사업체조사- 대상 범위 및 규모 : 2022년 기준 전국 사업체 조사, 식음료, 섬유/패션, 석유/화학, 제약/바이오, 고무/플라스틱, 철강, 금속/비금속, 반도체/전자, 기계/로봇, 자동차, 전기/에너지, 조선, 기타 제조업, 유통/물류에 해당하는 사업체 (약 60만개)- 대상지역 : 전국 6. 통계작성의 주기 : 1년 7. 통계작성의 방법 : 조사통계/일반통계
