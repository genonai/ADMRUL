# 통계작성의 승인(협의) 고시(여수시청년통계)
> 고시 · 행정규칙 · 시행 2021-12-21 · 공포 2021-12-15 · 제정

### 전문
1. 통계의 명칭 : 여수시청년통계 2. 통계작성기관의 명칭 : 전라남도 여수시 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제732004호 [2021.12.07.] 4. 통계작성의 목적 : 여수시 청년정책 수립을 위한 기초자료 작성 5. 통계작성의 대상- 대상 : 개인/개인- 모집단 : 여수시 주민등록인구 중 1981~2001년 출생자(만19~39세, 2020. 12. 31일 기준)- 대상 범위 및 규모 : 여수시 거주 청년세대(만 19~39세) 67,964명- 대상지역 : 시군구 6. 통계작성의 주기 : 3년 7. 통계작성의 방법 : 가공통계/일반통계
