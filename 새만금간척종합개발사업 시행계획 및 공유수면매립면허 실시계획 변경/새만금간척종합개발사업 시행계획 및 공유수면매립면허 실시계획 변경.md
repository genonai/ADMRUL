# 새만금 간척종합개발사업 편입토지 세목조서 변경
> 고시 · 행정규칙 · 시행 2011-08-05 · 공포 2011-08-05 · 일부개정

### 전문
1. 사 업 명 : 새만금 간척종합개발사업 2. 사업시행자 : 농림수산식품부장관 3. 사업지역 : 전라북도 군산시, 부안군, 김제시 4. 사업면적 : 40,100ha 5. 사업기간 : 1991년 11월 ~ 2020년 12월 6. 변경내용 : 새만금 내부개발 사업시행계획승인에 따른 방수제공사등 편입 토지 변경 7. 사업에 편입되는 토지 : 별지 참조? 당 초 : 892필지 2,682,596㎡,  ? 변 경 : 930필지 2,733,607㎡- 변경내용 : 고시해제 138필지 162,943㎡, 수용?사용할 추가 토지 176필지 213,954㎡ 8. 기타사항? 이전 고시된 토지의 세목조서는 종전 사항으로 갈음함? 기타 자세한 사항은 한국농어촌공사 새만금사업단 (☏063-540-5912)에 문의하시기 바랍니다.
