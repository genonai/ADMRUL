# 새만금 간척종합개발사업 사업기간 및 편입토지 세목조서 변경
> 고시 · 행정규칙 · 시행 2010-03-31 · 공포 2010-03-31 · 일부개정

### 전문
1. 사 업 명 : 새만금 간척종합개발사업 2. 사업시행자 : 농림수산식품부장관 3. 사업구역 : 전라북도 군산시, 김제시, 부안군 4. 사업기간? 당 초 : 1991년 11월 ~ 2011년 12월? 변 경 : 1991년 11월 ~ 2020년 12월 5. 수용 또는 사용할 토지의 세목조서 : 별 항? 당 초 : 598필지 2,156,569㎡? 변 경 : 892필지 2,682,596㎡ (추가 294필지 526,027㎡) 6. 기타사항 : 기타 자세한 사항은 한국농어촌공사 새만금사업단(☏063-540-5945)에 문의하시기 바랍니다.
