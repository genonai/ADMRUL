# 통계작성의 승인(협의) 고시(보건의료인력실태조사)
> 고시 · 행정규칙 · 시행 2021-10-24 · 공포 2021-10-18 · 제정

### 전문
1. 통계의 명칭 : 보건의료인력실태조사 2. 통계작성기관의 명칭 : 보건복지부 3. 통계작성승인(협의)번호 [작성승인(협의)일]: 제117110호 [2021.10.13.] 4. 통계작성의 목적 : 국내 보건의료인력의 전반적 현황과 실태를 조사하는 한편, 보건의료체계에서 양질의 보건의료인력을 양성하기 위한 정책의 근거를 제시하고자 함 5. 통계작성의 대상 : 보건의료인력 면허ㆍ자격 소지 20개 직종* 의사, 치과의사, 한의사, 조산사, 간호사, 간호조무사, 약사, 한약사, 임상병리사, 방사선사, 물리치료사, 작업치료사, 치과기공사, 치과위생사, 보건의료정보관리사, 안경사, 응급구조사, 영양사, 위생사, 보건교육사 6. 통계작성의 주기 : 3년 7. 통계작성의 방법 : 일반통계/ 가공통계
