# 금강(2)지구 대단위 농업개발사업 시행인가
> 고시 · 행정규칙 · 시행 2010-09-07 · 공포 2010-09-07 · 일부개정

### 전문
1. 사업지구명 : 금강(Ⅱ)지구 대단위농업개발사업 2. 사업목적 : 농업기반조성, 식량증산, 농가소득증대, 영농환경개선 3. 사업구역○ 충청남도- 부여군 충화, 양화, 임천, 세도면,- 서천군 장항, 서천읍, 마서, 화양, 기산, 한산, 마산, 시초, 문산, 종천면○ 전라북도- 군산시 옥구읍, 옥산, 회현, 임피, 서수, 대야, 개정, 성산, 나포면- 익산시 오산, 황등, 함라, 웅포, 낭산, 금마, 왕궁, 춘포, 삼기면- 김제시 죽산, 백산, 용지, 백구, 만경, 공덕, 청하, 성덕, 진봉, 금구, 봉남, 황산, 광활면- 완주군 삼례, 봉동읍, 용진, 이서, 고산, 비봉, 화산면 4. 사업면적 : 개발면적 43,000ha 5. 사업시행자○ 한국농어촌공사 사장 6. 주요사업개요○ 양수장 13개소, 용수로  610㎞, 배수장 4개소, 포장정비 16,251ha 7. 총사업비 : 776,181백만원 8. 사업효과 : 미곡증산(년간) 74,906M/T, 경지이용률 : 107％ → 145％투자수익률 16.6％ 9. 사업기간○ 당초 : 1989～2010년 (22개년)○ 변경 : 1989～2014년 (26개년)
