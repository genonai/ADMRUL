# 통계작성의 승인 고시(전라남도노인등록통계)
> 고시 · 행정규칙 · 시행 2018-12-24 · 공포 2018-12-18 · 제정

### 전문
1. 통계의 명칭 : 전라남도노인등록통계 2. 통계작성기관의 명칭 : 전라남도 3. 통계작성승인번호(작성승인일) : 제215008호(2018. 12. 12.) 4. 통계작성의 목적 : 전라남도의 맞춤형 고령인구 정책 수립의 기초자료를 제공하기 위함 5. 통계작성의 대상 : 전라남도에 거주하는 만65세이상 인구(‘17.11.1.기준) 6. 통계작성의 주기  : 3년 7. 통계작성의 방법  : 가공통계/일반통계
