# 홍보지구 대단위농업개발사업 편입토지 세목고시
> 고시 · 행정규칙 · 시행 2010-10-11 · 공포 2010-10-11 · 제정

### 전문
1. 사 업 명 : 홍보지구 대단위농업개발사업 2. 사업목적 : 수자원확보, 농업기반조성 3. 사업구역 : 1도 1시 1군 14개읍·면○ 충청남도 홍성군 홍성읍, 광천읍, 서부면, 결성면, 구항면,                     장곡면, 은하면, 홍동면, 갈산면보령시 오천면, 천북면, 주포면, 주교면, 청소면 4. 사업시행자 : 한국농어촌공사 사장 5. 사업기간 : 1991년 ∼ 2016년 (26개년) 6. 수용 또는 사용할 토지세목 조서 : 별항 7. 기타사항 :기타 자세한 사항은 한국농어촌공사  천수만사업단(041-630-5824)에 문의하시기 바랍니다.
