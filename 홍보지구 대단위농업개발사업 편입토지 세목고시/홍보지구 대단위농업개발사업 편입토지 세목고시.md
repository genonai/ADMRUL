# 홍보지구 대단위농업개발사업 편입토지 세목
> 고시 · 행정규칙 · 시행 2016-08-01 · 공포 2016-08-01 · 일부개정

### 전문
1. 사업종류 : 농업생산기반정비사업 2. 사업지구명 : 홍보지구 대단위농업개발사업 3. 사업목적 : 수자원 확보, 농업기반 조성 4. 사업구역 : 1도 1시 1군 14개 읍·면○ 충청남도 보령시 오천면, 천북면, 주포면, 주교면, 청소면홍성군 홍성읍, 광천읍, 서부면, 결성면, 구항면, 장곡면, 은하면, 홍동면, 갈산면 5. 사업시행자 : 한국농어촌공사 사장 6. 사업기간 : 1991년 ～ 2018년(28년) 7. 수용 또는 사용할 토지세목조서 : 별항 8. 기타사항기타 자세한 사항은 한국농어촌공사(우58217 전남 나주시 그린로20, 전화 061-338-5384)나 한국농어촌공사 천수만사업단(우32226 충남 홍성군 홍성읍 월산로58, 전화 041-630-5825)에 문의 바랍니다.
