# 통계작성의 승인 고시(고양시경제지표조사)
> 고시 · 행정규칙 · 시행 2017-06-19 · 공포 2017-06-19 · 제정

### 전문
1. 통계의 명칭 : 고양시경제지표조사 2. 통계작성기관의 명칭 : 경기도 고양시 3. 통계작성승인번호(작성승인일) : 제620004호(2017. 06. 16.) 4. 통계작성의 목적 : 고양시의 경제상황을 파악하여 경제정책 수립을 위한 기초자료로 활용하기 위함 5. 통계작성의 대상 : 사업체 6. 통계작성의 주기 : 1년 7. 통계작성의 방법 : 조사통계
