# 통계작성의 변경승인 고시(ICT기업경기조사)
> 고시 · 행정규칙 · 시행 2016-08-08 · 공포 2016-08-08 · 일부개정

### 전문
1. 통계의 명칭 : ICT기업경기조사 2. 통계작성기관의 명칭 : 한국정보통신진흥협회, 한국전자정보통신산업진흥회 3. 통계작성승인번호(작성승인일) : 제92004호(2003. 10. 28.) 4. 통계작성의 변경 연월일 : 2016. 08. 02. 5. 통계작성의 변경 내용과 사유 : 조사항목 설명추가(통계정확성제고)
