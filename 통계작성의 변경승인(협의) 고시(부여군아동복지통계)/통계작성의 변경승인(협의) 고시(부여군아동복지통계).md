# 통계작성의 작성승인(협의) 고시(부여군아동복지통계)
> 고시 · 행정규칙 · 시행 2022-04-04 · 공포 2022-03-29 · 제정

### 전문
1. 통계의 명칭 : 부여군아동복지통계 2. 통계작성기관의 명칭 : 충청남도 부여군 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제700004호 [2022.03.21.] 4. 통계작성의 목적 : 부여군  아동복지 정책수립의 기초자료 제공 5. 통계작성의 대상- 모집단 : 통계작성 기준시점 부여군 주민등록에 등재된 만 18세 미만 아동인구- 대상 범위 및 규모 : 통계작성 기준시점 부여군 주민등록에 등재된 만 18세 미만 아동인구- 대상지역 : 동읍면 6. 통계작성의 주기 : 2년 7. 통계작성의 방법 : 가공통계/일반통계
