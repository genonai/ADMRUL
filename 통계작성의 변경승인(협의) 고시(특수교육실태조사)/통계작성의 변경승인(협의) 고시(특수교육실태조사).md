# 통계작성의 변경승인 고시(특수교육실태조사)

### 전문
1. 통계의 명칭 : 특수교육실태조사 2. 통계작성기관의 명칭 : 교육부 3. 통계작성승인번호(작성승인일) : 제112014호(2008. 08. 28.) 4. 통계작성의 변경 연월일 : 2017. 06. 29. 5. 통계작성의 변경 내용과 사유 : 조사항목 개선 (항목 현행화 및 응답자 이해도 개선)
