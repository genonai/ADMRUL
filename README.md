# ADMRUL

행정규칙(고시·훈령·예규) 수집 데이터

## 출처 및 라이선스

- **원천 데이터**: 법제처 국가법령정보센터(https://www.law.go.kr) — 국가법령정보 공동활용 OpenAPI(https://open.law.go.kr)를 통해 수집.
- **저작권**: 국가·지방자치단체의 고시·공고·훈령 그 밖에 이와 유사한 것은 저작권법 제7조(보호받지 못하는 저작물)에 따라 저작권 보호 대상이 아니다.
- **출처 표기**: 이 데이터를 이용·재배포할 때는 출처(법제처 국가법령정보센터)를 표기한다.
- **유의**: 국가법령정보는 법적 효력을 갖는 원본과 차이가 있을 수 있다. 이 저장소의 JSON/MD 는 원천을 기계 가공한 수집 시점 스냅샷이다.
