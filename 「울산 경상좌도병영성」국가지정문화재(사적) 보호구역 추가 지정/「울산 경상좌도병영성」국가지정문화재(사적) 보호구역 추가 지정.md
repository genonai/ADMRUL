# 「울산 경상좌도병영성」보호구역 추가 지정
> 고시 · 행정규칙 · 시행 2018-01-19 · 공포 2018-01-19 · 일부개정

### 전문
1. 고 시 명 : 「울산 경상좌도병영성」 보호구역 추가 지정 2. 고시사항가. 대상문화재 : 사적 제320호 「울산 경상좌도병영성」ㅇ 소재지 : 울산시 중구 서동 일원나. 보호구역 추가 지정 사항ㅇ 울산광역시 중구 동동 830-7번지 등 2필지 621㎡다. 추가 지정 사유ㅇ 추가지정 대상부지는 울산 경상좌도병영성 북문 옹성과 동문지 옹성 해자 인접 지역이고.      기존 지정되어 있는 문화재 구역과 단절 구역 발생을 방지하여 효율적인 문화재 보존·관리를 위해 문화재보호구역으로 지정하여 관리하고자 함 3. 지 정 일 : 관보 고시일 4. 특기사항ㅇ「토지이용계획 기본법」
제8조(지역·지구등의 지정 등)에 따른 지형도면 등은 ‘문화재공간정보(GIS)서비스(http://www.gis-heritage.go.kr) 알림마당-지형도면고시’에서 열람이 가능합니다. 5. 연 락 처가. 문화재청ㅇ 문화재청 문화재보존국 보존정책과 : 전화 042-481-4847 / 팩스 042-481-4849- 주소 : (우 35208) 대전광역시 서구 청사로 189 정부대전청사 1동- 홈페이지 : http://www.cha.go.kr나. 지방자치단체ㅇ 울산광역시 문화예술과 : 전화 052-229-3733/팩스 052-229-3791- 주소 : (우 44675) 울산광역시 남구 중앙로 201(신정동)- 홈페이지 : http://www.ulsan.go.krㅇ 울산광역시 중구 문화관광실  : 전화 052-290-4452/팩스 052-290-3659- 주    소 : (우 44475) 울산광역시 중구 단장골길1(복산동)- 홈페이지 : http://www.junggu.ulsan.kr 6. 사적 보호구역 추가 지정 지번별 면적조서(단위 : ㎡)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=33212336) 7. 보호구역 추가지정 대상 지적도(*추가대상은 확대지적도 빨강색선 표시지역)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=33212421)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=33212422)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=33212423)
