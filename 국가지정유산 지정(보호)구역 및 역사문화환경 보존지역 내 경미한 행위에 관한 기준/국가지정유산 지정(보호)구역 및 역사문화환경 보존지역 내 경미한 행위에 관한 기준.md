# 국가지정문화재 주변 경미한 현상변경 행위
> 고시 · 행정규칙 · 시행 2015-05-08 · 공포 2015-05-08 · 일부개정

### 전문
1. 고 시 명 :「국가지정문화재 주변 경미한 현상변경 행위」 2. 고시내용가. 내    용ㅇ 국가지정문화재 주변 경미한 현상변경 행위 ([붙임] 참조)나. 관련근거ㅇ 문화재보호법 제35조, 문화재보호법 시행령 제21조의3 제4호다. 적    용ㅇ 시장?군수?구청장은 동 고시 범위 내에 해당하는 행위에 대하여는 문화재 보존 영향검토 또는 문화재청에 현상변경 등 허가 신청 없이 자체적으로 허가 또는 변경허가를 할 수 있음라. 동 고시의 재검토기한 : 2017. 12. 31까지 3. 기준 시행일 : 관보고시일 4. 연 락 처 : 문화재청 보존정책과ㅇ 주  소 : (우)302-701 대전광역시 서구 청사로 189번지 정부대전청사 1동ㅇ 연락처 : 전화 (042)481-4835, 4837, 전자메일 yayagom@korea.kr
