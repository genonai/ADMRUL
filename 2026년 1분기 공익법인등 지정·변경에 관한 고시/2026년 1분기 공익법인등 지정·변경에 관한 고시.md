# 2010.1/4분기 지정기부금단체 지정공고
> 공고 · 행정규칙 · 시행 2010-03-31 · 공포 2010-03-31 · 제정

### 전문
1. 신규 지정기부금단체![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=5066019)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=5066020)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=5066021)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=5066022)ㅇ 지정기부금단체로 인정되는 기한 : 2015년 12월 31일2. 명칭이 변경된 지정기부금단체ㅇ 변경전 법인명 : 사단법인 청지실천연합변경후 법인명 : 사단법인 천심녹색성장4대강살리기실천연합ㅇ 변경전 법인명 : 사단법인 좋은나라나눔운동본부변경후 법인명 : 사단법인 프로보노코리아ㅇ 변경전 법인명 : 사단법인 국민생활체육협의회변경후 법인명 : 사단법인 국민생활체육회ㅇ 변경전 법인명 : 사단법인 한국이주노동자건강협회변경후 법인명 : 사단법인 한국이주민건강협회ㅇ 변경전 법인명 : 재단법인 한국전자통관국제화재단변경후 법인명 : 재단법인 국가관세종합정보망운영연합회ㅇ 변경전 법인명 : 사단법인 국제10021클럽변경후 법인명 : 사단법인 국제지도자연합ㅇ 변경전 법인명 : 사단법인 대한명인문화예술교류회변경후 법인명 : 사단법인 대한명인회ㅇ 변경전 법인명 : 사단법인 한국복지정보화협회변경후 법인명 : 사단법인 한국아이티복지진흥원3. 기타ㅇ 관보 제17164호(2009.12.31)의 기획재정부공고제2009-197호(기부금단체지정)에 게재된 (사)청소년문화예술협회를 사단법인 청소년문화예술단체로 정정하여 공고합니다.4. 부칙이 공고는 공고한 날부터 시행한다. 다만, 공고일 이전에 지출한 기부금도 공고일이 속하는 사업연도에 지출한 경우에는 「법인세법」 제24조제1항에 따른 지정기부금으로 본다.
