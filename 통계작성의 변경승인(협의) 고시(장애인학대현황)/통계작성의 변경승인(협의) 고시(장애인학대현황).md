# 통계작성의 승인(협의) 고시(장애인학대현황)
> 고시 · 행정규칙 · 시행 2020-04-13 · 공포 2020-04-07 · 제정

### 전문
1. 통계의 명칭 : 장애인학대현황 2. 통계작성기관의 명칭 : 보건복지부 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제117108호[2020. 3. 31.] 4. 통계작성의 목적 : 장애인학대 관련 통계자료를 작성하여 학대예방, 피해자 지원 등에 필요한 기초자료 제공 5. 통계작성의 대상 : 장애인권익옹호기관으로 학대 신고 접수된 건수 6. 통계작성의 주기  : 1년 7. 통계작성의 방법  : 보고/일반통계
