# 통계작성의 작성승인 고시(의료급여통계)
> 고시 · 행정규칙 · 시행 2016-07-04 · 공포 2016-07-04 · 제정

### 전문
1. 통계의 명칭 : 의료급여통계 2. 통계작성기관의 명칭 : 국민건강보험공단, 건강보험심사평가원 3. 통계작성승인번호(작성승인일) : 제92015호(2016. 06. 30.) 4. 통계작성의 목적 : 보건의료정책 참고자료 및 분석통계 기초자료로 활용 5. 통계작성의 대상 : 의료급여법에 의거한 의료급여 수급권자 6. 통계작성의 주기 : 1년 7. 통계작성의 방법 : 보고통계
