# 천연기념물(동물) 현상변경 허가권한 시·도 위임
> 고시 · 행정규칙 · 시행 2009-06-10 · 공포 2009-06-10 · 제정

### 전문
1. 고 시 명 : 천연기념물(동물) 현상변경 허가권한 시·도 위임 2. 고시내용가. 수임기관 : 전국 16개 시·도 자치단체나. 위임내용ㅇ 대 상 종- 황조롱이(천연기념물 제323-8호)- 수리부엉이(천연기념물 제324-2호)- 솔부엉이(천연기념물 제324-3호)- 소 쩍 새(천연기념물 제324-6호)ㅇ 위임권한 : 죽은 것에 대한 매장 또는 소각하는 행위의 허가 및 그 취소다. 수임사무 처리지침 : 공문 통보 3. 시 행 일 : 관보고시일 4. 연 락 처가. 문화재청 천연기념물과ㅇ 주  소 : (우)302-701 대전광역시 서구 선사로139 정부대전청사 1동ㅇ 연락처 : 전화 (042)481-4981～3, 전송 (042)481-4999ㅇ 홈페이지 : http://www.cha.go.kr, 전자메일 mood82@ocp.go.kr
