# 서산A간척지 농업기반시설 재정비사업 방수제공사 편입토지 세목고시
> 고시 · 행정규칙 · 시행 2010-12-13 · 공포 2010-12-13 · 일부개정

### 전문
1. 사 업 명 : 서산A간척지 농업기반시설 재정비사업 방수제공사 2. 사업목적 : 노후된 농업기반 시설의 기능개선, 침수방지 및 재해대비  능력보강, 기업영농에서 다수개별 영농체계로 전환에 따른  기반시설의 재정비 3. 사업구역 : 1도 2시·군 8개읍?면?동○ 충청남도 서산시 해미면, 고북면, 인지면, 부석면, 장동, 양대동, 홍성군 갈산면, 서부면 4. 사업시행자 : 한국농어촌공사 사장 5. 사업기간 : 2008년 ∼ 2012년 (5개년) 6. 수용 또는 사용할 토지세목 조서 : 별항 7. 기타사항 : 기타 자세한 사항은 한국농어촌공사 천수만사업단(041-630-5857)에 문의하시기 바랍니다.
