# 통계작성의 변경승인 고시(외래관광객실태조사)
> 고시 · 행정규칙 · 시행 2017-01-23 · 공포 2017-01-23 · 일부개정

### 전문
1. 통계의 명칭 : 외래관광객실태조사 2. 통계작성기관의 명칭 : 문화체육관광부 3. 통계작성승인번호(작성승인일) : 제314002호(1980. 5. 8.) 4. 통계작성의 변경 연월일 : 2017. 1. 16. 5. 통계작성의 변경 내용과 사유○ 주요 변경내용- 조사장소의 변경 : (기존) 6곳 → (변경) 8곳- 조사대상국의 변경 : (기존) 16개국 → (변경) 19개국- 조사항목의 변경 : 지출경비 및 연수입에 대한 화폐단위 추가, 방문지역의 항목조정 등- 표본수의 확대 : (기존) 12,900명 → (변경) 13,200명- 작성체계의 변경 : (기존) 한국문화관광연구원 → (변경) 한국관광공사○ 사유 : 조사의 정확성 확보
