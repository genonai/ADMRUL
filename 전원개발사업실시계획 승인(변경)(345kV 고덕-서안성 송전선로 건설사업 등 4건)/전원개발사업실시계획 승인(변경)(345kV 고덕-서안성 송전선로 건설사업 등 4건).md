# 전원개발사업 실시계획 승인(변경)(345kV 고덕-서안성 송전선로 건설사업)

### 전문
1. 사업의 명칭 : 345kV 고덕-서안성 송전선로 건설사업 2. 사업시행자의 성명 및 주소 : 한국전력공사 사장 정승일전라남도 나주시 전력로 55 (빛가람동) 3. 변경사유 :  민원협의 결과(터널 경과지 변경)에 따른 위치변경 4. 변경내역□ 사업면적![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119764383) 변 경 내 용 비 교 표1. 토지 증감표1) 철탑 : 변경없음2) 선하지 : 변경없음3) 전력구(단위 : ㎡)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119764385) 2. 토지이외의 물건 증감표 : 변경없음 3. 도시계획시설(전기공급설비) 결정 변경명세1) 철탑부지 : 변경없음2) 선하지부지 : 변경없음3) 전력구(단위 : ㎡)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119765067)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119765069)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=119765071) 4. 토지 등의 소유자와 이해관계인의 성명 및 주소 : 별항
