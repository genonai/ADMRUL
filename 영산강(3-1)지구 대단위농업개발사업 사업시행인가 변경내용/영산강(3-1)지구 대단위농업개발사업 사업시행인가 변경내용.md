# 영산강(3-1)지구 공유수면매립공사 실시계획 변경인가
> 고시 · 행정규칙 · 시행 2010-02-08 · 공포 2010-02-08 · 제정

### 전문
1.실시계획 인가 연월일 : 1987년 6월 9일(특개27620-1092호)○ 변경인가 연월일 : 2010년 2월 8일(농업기반과-734호) 2. 면허를 받은자의 성명·주소 : 한국농어촌공사사장○ 법인의 주소 : 경기도 의왕시 포일동 487번지 (전화 031-420-3666)○ 대표자 성명(법인등록번호) : 홍문표(135271-0000021) 3. 매립목적 : 농경지조성 및 국토확장 4. 매립공사 구역의 위치 및 면적○ 위 치 : 전남 해남군 산이·마산·계곡면, 영암군 삼호·미암면 지선○ 면 적 : 128,160,000㎡ 5. 공사기간○ 당 초 : 1987년 6월 9일 ～ 2009년 12월 31일(22년 7개월)○ 변 경 : 1987년 6월 9일 ～ 2015년 12월 31일(28년 7개월) 6. 실시계획의 변경사유 및 변경사항○ 변경사유 : 정부 예산의 투자계획 조정에 따라 공사기간 연기○ 변경사항 : 공사기간 6년 연장
