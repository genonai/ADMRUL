# 통계작성의 승인 고시(국방통계)
> 고시 · 행정규칙 · 시행 2019-02-27 · 공포 2019-02-21 · 제정

### 전문
1. 통계의 명칭 : 국방통계 2. 통계작성기관의 명칭 : 국방부 3. 통계작성승인번호(작성승인일) : 제122009호(2019. 2. 14.) 4. 통계작성의 목적 : 국방정책의 수립 및 평가 등에 활용하기 위함 5. 통계작성의 대상 : 국방관련 현황 6. 통계작성의 주기  : 1년 7. 통계작성의 방법  : 보고통계/일반통계
