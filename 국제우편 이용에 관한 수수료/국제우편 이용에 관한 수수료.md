# 국제우편 부가서비스 이용에 관한 수수료
> 고시 · 행정규칙 · 시행 2012-07-01 · 공포 2012-06-08 · 제정

### 전문
1. 통상우편물가. 국제반신 우표권o 판 매 : 1,450원o 교 환 : 740원나. 등기료 : 2,500원다. 속달료 : 2,500원라. 통관 회부료o 통관 대상 발송 우편물 : 1,000원o 관세 부과 도착 우편물 : 2,000원o 우편자루 배달 인쇄물  : 4,000원마. 행방 조사 청구료o 항공우편청구 : 무료o 국제특급우편(EMS) 청구 : 해당요금o 팩스청구 : 3,000원바. 배달통지청구료(등기한) : 1,500원사. 주소변경 및 환부 청구료o 외국으로 발송전 : 국내 FAX 1종 요금o 외국으로 발송후 항공우편청구 : 1,800원o 외국으로 발송후 팩스청구 : 4,800원아. 보험료o 기본요금 : 2,500원o 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원자. 국제우편요금 수취인 부담 취급 수수료o 인쇄물 : 950원o 엽  서 : 400원차. 등기우편물 반착료(반송취급료) :  국내우편등기료(무료등기는 제외) 2. 국제특급우편물(EMS)가. 보험료o 기본요금 : 2,500원o 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원나. 통관 회부료(관세부과된 도착 국제특급) : 4,000원다. 배달 통지 청구료 : 1,500원라. 행방조사 청구료 : 무료마. 주소변경 및 환부 청구료o 외국으로 발송전 : 국내 FAX 1종 요금o 외국으로 발송후 우편청구 : 1,800원o 외국으로 발송후 팩스청구 : 4,800원바. 초특급 수수료o 접수익일(J+1) : 3,000원 3. 소포우편물가. 보험료o 기본요금 : 2,500원o 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원나. 통관 회부료o 관세부과된 도착 및 반착소포 : 4,000원다. 배달통지 청구료 : 1,500원라. 행방조사 청구료o 항공우편청구 : 무료o 국제특급우편(EMS) 청구 : 해당요금o 팩스청구 : 3,000원마. 주소변경 및 환부청구료o 외국으로 발송전 : 국내 FAX 1종 요금o 외국으로 발송후 우편청구 : 1,800원o 외국으로 발송후 팩스청구 : 4,800원바. 재포장료 : 무료사. 보관료(유료보관기간 : 8일) : 1일마다 750원
