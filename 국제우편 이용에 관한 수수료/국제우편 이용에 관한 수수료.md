# 국제우편 이용에 관한 수수료
> 고시 · 행정규칙 · 시행 2018-01-01 · 공포 2017-12-19 · 일부개정

### 전문
1. 통상우편물가. 국제반신 우표권ㅇ 판 매 : 1,450원ㅇ 교 환 : 항공서장 4지역 20g 해당요금나. 등기료 : 2,800원다. 통관절차대행수수료ㅇ 통관 대상 발송 우편물 : 1,000원ㅇ 관세 부과된 도착 우편물 : 2,000원ㅇ 우편자루 배달 인쇄물  : 4,000원라. 행방조사 청구료ㅇ 항공우편청구 : 무료ㅇ 국제특급우편(EMS) 청구 : 해당요금마. 배달통지청구료(등기한) : 1,500원바. 주소변경 및 환부 청구료ㅇ 외국으로 발송준비 완료 전- 접수국 발송준비 완료 전 : 무료- 접수국 발송 후 : 국내등기취급수수료ㅇ 외국으로 발송준비 완료 후- 항공우편 청구 : 1,800원- 팩스 청구 : 4,800원사. 등기우편물 반송료(반송취급료) : 국내우편등기료(무료등기는 제외)아. 보험료ㅇ 기본요금 : 550원ㅇ 추가배달료(보험가입 시 필수) : 1,300원ㅇ 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원자. 국제우편요금 수취인 부담 취급 수수료ㅇ 인쇄물(봉투) 50g까지 : 1,100원ㅇ 엽  서 : 500원 2. 국제특급우편물(EMS)가. 통관절차대행수수료ㅇ 관세 부과된 도착 우편물 : 4,000원나. 배달통지청구료 : 1,500원다. 주소변경 및 환부 청구료ㅇ 외국으로 발송준비 완료 전- 접수국 발송준비 완료 전 : 무료- 접수국 발송 후 : 국내등기취급수수료ㅇ 외국으로 발송 후- 항공우편 청구 : 1,800원- 팩스 청구 : 4,800원라. 초특급 서비스 수수료ㅇ 접수익일(J+1) : 4,500원ㅇ 대상국가(도시) : 홍콩, 베트남(하노이, 호치민)ㅇ 접수관서 및 접수마감시각 : 서울·경인지방우정청 국내특급우편 취급 고시사항의 당일특급접수우체국 및 취급시간 참조마. 보험료ㅇ 기본요금 : 2,800원ㅇ 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원바. EMS 방문접수 수수료(계약고객 제외)ㅇ 1회 방문 1통 당 3,000원, 추가 1통 당 1,000원(최대 5,000원) 3. 소포우편물가. 통관절차대행수수료ㅇ 관세 부과된 도착 및 반착 우편물 : 4,000원나. 행방조사 청구료ㅇ 항공우편청구 : 무료ㅇ 국제특급우편(EMS) 청구 : 해당요금다. 배달통지청구료 : 1,500원라. 주소변경 및 환부 청구료ㅇ 외국으로 발송준비 완료 전- 접수국 발송준비 완료 : 무료- 접수국 발송 후 : 국내등기취급수수료ㅇ 외국으로 발송 후- 항공우편 청구 : 1,800원- 팩스 청구 : 4,800원마. 등기우편물 반송료(반송취급료) : 배달국가의 반송요금바. 보험료ㅇ 기본요금 : 2,800원ㅇ 추가요금(보험가액 65.34 SDR 또는 114,300원 초과마다) : 550원
