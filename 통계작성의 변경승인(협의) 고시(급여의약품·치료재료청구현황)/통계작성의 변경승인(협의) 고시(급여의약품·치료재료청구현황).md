# 통계작성의 작성승인고시(급여의약품청구현황)
> 고시 · 행정규칙 · 시행 2016-04-25 · 공포 2016-04-25 · 제정

### 전문
1. 통계의 명칭 : 급여의약품청구현황 2. 통계작성기관의 명칭 : 건강보험심사평가원 3. 통계작성승인번호(작성승인일) : 제35404호(2016. 04. 18.) 4. 통계작성의 목적 : 급여의약품 약제관리 체계강화, 시계열적 관리, 대내외 통계정보 수요에 대한 대응체계 마련 5. 통계작성의 대상 : 요양기관이 약제급여비용으로 청구한 급여의약품 6. 통계작성의 주기 : 1년 7. 통계작성의 방법 : 보고통계
