# 건축자재 오염물질 방출 확인 시험기관 지정고시

1. 기관명 : 서울특별시 보건환경연구원가. 대표자 : 정 권나. 소재지 : 경기도 과천시 장군마을 3길 30다. 지정번호 : 해당사항 없음라. 지정 확인기관 : 법정기관 2. 시험기관명 : (재)한국기계전기전자시험연구원가. 대표자 : 송유종나. 소재지 : 경기도 군포시 흥안대로 27번길 22다. 지정번호 : 한강-2017-01호라. 지정 확인기관 : 한강유역환경청 3 시험기관명 : (재)한국환경수도연구원가. 대표자 : 김정근나. 소재지 : 서울특별시 영등포구 양평로 28사길 29다. 지정번호 : 한강-2017-02호라. 지정 확인기관 : 한강유역환경청 4. 시험기관명 : (재)한국화학융합시험연구원가. 대표자 : 변종립나. 소재지 : 경기도 과천시 교육원로 98다. 지정번호 : 한강-2017-03호라. 지정 확인기관 : 한강유역환경청 5. 시험기관명 : ㈜푸른환경산업연구소가. 대표자 : 김홍기나. 소재지 : 서울특별시 관악구 청림3길 9, 그린빌딩 3,4층다. 지정번호 : 한강-2017-04호라. 지정 확인기관 : 한강유역환경청 6. 시험기관명 : 한국에스지에스(주)가. 대표자 : 권이성나. 소재지 : 경기도 안양시 동안구 엘에스로 76다. 지정번호 : 한강-2017-05호라. 지정 확인기관 : 한강유역환경청 7. 시험기관명 : 삼화페인트 공업(주)가. 대표자 : 오진수나. 소재지 : 경기도 안산시 단원구 별망로 178다. 지정번호 : 한강-2017-06호라. 지정 확인기관 : 한강유역환경청 8. 시험기관명 : (재)한국건설생활환경시험연구원가. 대표자 : 김경식나. 소재지 : 경기도 군포시 공단로 149 아이밸리 805호다. 지정번호 : 한강-2017-07호라. 지정 확인기관 : 한강유역환경청 9. 시험기관명 : (재)FITI시험연구원가. 대표자 : 김영찬나. 소재지 : 충청북도 청주시 청원구 오창읍 양청3길 21다. 지정번호 : 금강-2017-01호라. 지정 확인기관 : 금강유역환경청 10. 시험기관명 : ㈜태성환경연구소가. 대표자 : 윤기열나. 소재지 : 울산광역시 울주군 온산읍 회학3길 56-20다. 지정번호 : 낙동강-2017-01호라. 지정 확인기관 : 낙동강유역환경청 11. 시험기관명 : ㈜디케이사이언스가. 대표자 : 이재인나. 소재지 : 서울특별시 마포구 만리재로 110 DK B/D다. 지정번호 : 한강-2017-08호라. 지정 확인기관 : 한강유역환경청
