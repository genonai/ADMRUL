# 건축자재 오염물질 방출 확인 시험기관 지정고시
> 고시 · 행정규칙 · 시행 2017-01-17 · 공포 2017-01-17 · 제정

### 전문
1. 시험기관명 : 서울특별시 보건환경연구원가. 대표자 : 정 권나. 주  소 : 경기도 과천시 장군마을 3길 30 2. 시험기관명 : 한국기계전기전자시험연구원가. 대표자 : 송유종나. 주  소 : 경기도 군포시 흥안대로 27번길 22 3 시험기관명 : (재)한국환경수도연구원가. 대표자 : 김정근나. 주  소 : 서울특별시 영등포구 양평로 28사길 29 4. 시험기관명 : (재)한국화학융합시험연구원가. 대표자 : 변종립나. 주  소 : 경기도 과천시 교육원로 98 5. 시험기관명 : ㈜푸른환경산업연구소가. 대표자 : 김홍기나. 주  소 : 서울특별시 관악구 청림3길 9, 그린빌딩 3,4층 6. 시험기관명 : 한국에스지에스(주)가. 대표자 : 권이성나. 주  소 : 경기도 안양시 동안구 엘에스로 76
