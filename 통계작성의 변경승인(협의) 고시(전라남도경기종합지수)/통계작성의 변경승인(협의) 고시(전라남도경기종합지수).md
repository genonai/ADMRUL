# 통계작성의 변경승인 고시(전라남도경기종합지수)
> 고시 · 행정규칙 · 시행 2018-04-29 · 공포 2018-04-23 · 일부개정

### 전문
1. 통계의 명칭 : 전라남도경기종합지수 2. 통계작성기관의 명칭 : 전라남도 3. 통계작성승인번호(작성승인일) : 제215006호(2017. 5. 24.) 4. 통계작성의 변경 연월일 : 2018. 4. 18. 5. 통계작성의 변경 내용과 사유 :![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=34213547)※ 기준시점 변경은 2개 지표임 : 광공업생산지수, 대형소매점판매액지수
