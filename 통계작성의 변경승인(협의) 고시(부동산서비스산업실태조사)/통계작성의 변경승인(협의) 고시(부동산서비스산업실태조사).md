# 통계작성의 승인(협의) 고시(부동산서비스산업실태조사)
> 고시 · 행정규칙 · 시행 2023-10-05 · 공포 2023-10-10 · 제정

### 전문
1. 통계의 명칭 : 부동산서비스산업실태조사 2. 통계작성기관의 명칭 : 국토교통부 3. 통계작성승인(협의)번호 [작성승인(협의)일] : 제116077호 [2023.10.05.] 4. 통계작성의 목적 : 부동산서비스산업 진흥에 필요한 기초 자료의 확보 5. 통계작성의 대상- 대상 : 사업체/사업체- 모집단 : 부동산서비스산업을 통해 경제적 또는 사회적 부가가치를 창출하고 있는 전국의 종사자 수 1인 이상의 사업체- 대상 범위 및 규모 : 매년 작성일 기준 부동산서비스산업을 영위하는 사업체 약 28만개- 대상지역 : 전국 6. 통계작성의 주기 : 1년 7. 통계작성의 방법 : 조사통계/일반통계
