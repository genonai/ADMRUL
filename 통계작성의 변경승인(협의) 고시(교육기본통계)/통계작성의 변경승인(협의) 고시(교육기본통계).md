# 통계작성의 변경승인 고시(교육기본통계)
> 고시 · 행정규칙 · 시행 2018-04-08 · 공포 2018-04-02 · 일부개정

### 전문
1. 통계의 명칭 : 교육기본통계 2. 통계작성기관의 명칭 : 한국교육개발원 3. 통계작성승인번호(작성승인일) : 제334001호(1998. 12. 21.) 4. 통계작성의 변경 연월일 : 2018. 03. 29. 5. 통계작성의 변경 내용과 사유 : 작성항목 변경 (붙임 참조)
