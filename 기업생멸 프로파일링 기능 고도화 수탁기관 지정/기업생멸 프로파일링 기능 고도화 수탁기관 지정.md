# 기업생멸 프로파일링 기능 고도화 수탁기관 지정
> 고시 · 행정규칙 · 시행 2015-04-07 · 공포 2015-04-07 · 제정

### 전문
1. 수탁기관 : 재단법인 한국통계정보원ㅇ 주 소 : 대전광역시 서구 청사로 152 이안빌딩 3층 304호 2. 위탁업무ㅇ 업 무 명 : 기업생멸 프로파일링 기능 고도화 위탁 사업ㅇ 위탁내용- 기업생멸 프로파일링 기능 고도화- 기업지배구조 변화 DB 구축 및 분석 강화 등ㅇ 처리방법- 위탁기관에 상주하여 업무 처리- Help Desk 운영 3. 위탁기간 : 계약 체결일 ～ 2015. 11. 30.
