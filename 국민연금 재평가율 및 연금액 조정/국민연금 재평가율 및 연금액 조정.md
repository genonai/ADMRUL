# 국민연금 기준소득월액 재평가율 및 연금액 조정
> 고시 · 행정규칙 · 시행 2010-04-01 · 공포 2010-03-17 · 전부개정

### 전문
1. 2010년도 국민연금 기준소득월액 재평가율가. 재평가율![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=4283982)나. 적용대상○ 2010년 4월부터 2011년 3월의 기간 동안에 지급이 개시되는 급여를 지급받을 권리를 가지는 자2. 2010년도 연금액 조정가. 기본연금액○ 조정대상 : 기존 수급권자○ 조 정 액 : 2.8% 증액○ 적용기간 : 2010년 4월분부터 2011년 3월분까지 적용나. 부양가족연금액○ 조정대상 : 모든 수급권자 중 부양가족연금 계산 대상자○ 조 정 액 : 2.8% 증액- 배  우  자 : 연 214,860원 → 연 220,870원- 자녀?부모 : 연 143,220원 → 연 147,230원○ 적용기간 : 2010년 4월분부터 2011년 3월분까지 적용
