# 국민연금 재평가율 및 연금액 조정
> 고시 · 행정규칙 · 시행 2011-04-01 · 공포 2011-03-15 · 일부개정

### 전문
1. 2011년도 국민연금 기준소득월액 재평가율가. 재평가율 결정![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=5400288)나. 적용대상○ 2011년 4월부터 2012년 3월의 기간 동안에 지급이 개시되는 급여를 지급받을 권리를 가지는자2. 2011년도 연금액 조정가. 기본연금액○ 조정대상 : 기존 수급권자○ 조 정 액 : 2.9% 증액○ 적용기간 : 2011년 4월분부터 2012년 3월분까지 적용나. 부양가족연금액○ 조정대상 : 모든 수급권자 중 부양가족연금 계산 대상자○ 조 정 액 : 2.9% 증액- 배 우 자 : 연 220,870원 → 연 227,270원(6,400원↑)- 자녀?부모 : 연 147,230원 → 연 151,490원(4,260원↑)○ 적용기간 : 2011년 4월분부터 2012년 3월분까지 적용
