# 국민연금 재평가율 및 연금액 조정
> 고시 · 행정규칙 · 시행 2023-01-19 · 공포 2023-01-19 · 일부개정

### 전문
1. 2023년도 국민연금 기준소득월액 재평가율가. 재평가율 결정![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=124510821)나. 적용대상○ 2023년 1월부터 2023년 12월까지의 기간 동안에 지급이 개시되는 급여를 지급 받을 권리를 가지는 자 2. 2023년도 연금액 조정가. 기본연금액○ 조정대상 : 기존 수급권자○ 조 정 액 : 5.1% 증액○ 적용기간 : 2023년 1월분부터 2023년 12월분까지 적용나. 부양가족연금액○ 조정대상 : 모든 수급권자 중 부양가족연금 계산 대상자○ 조 정 액 : 5.1% 증액- 배  우  자 : 연 269,630원 → 연 283,380원(13,750원↑)- 자녀ㆍ부모 : 연 179,710원 → 연 188,870원(9,160원↑)○ 적용기간 : 2023년 1월분부터 2023년 12월분까지 적용
