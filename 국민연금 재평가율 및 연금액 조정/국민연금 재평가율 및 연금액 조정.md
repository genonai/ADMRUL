# 국민연금 재평가율 및 연금액 조정
> 고시 · 행정규칙 · 시행 2014-04-01 · 공포 2014-03-28 · 일부개정

### 전문
1. 2014년도 국민연금 기준소득월액 재평가율가. 재평가율 결정![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=16927120)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=16927145)나. 적용대상○ 2014년 4월부터 2015년 3월까지의 기간 동안에 지급이 개시되는 급여를 지급받을 권리를 가지는 자 2. 2014년도 연금액 조정가. 기본연금액○ 조정대상 : 기존 수급권자○ 조 정 액 : 1.3% 증액○ 적용기간 : 2014년 4월분부터 2015년 3월분까지 적용나. 부양가족연금액○ 조정대상 : 모든 수급권자 중 부양가족연금 계산 대상자○ 조 정 액 : 1.3% 증액- 배  우  자 : 연 241,550원 → 연 244,690원(3,140원↑)- 자녀·부모 : 연 161,000원 → 연 163,090원(2,090원↑)○ 적용기간 : 2014년 4월분부터 2015년 3월분까지 적용
