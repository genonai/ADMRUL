# 통계작성의 변경승인 고시(장애인고용패널조사)
> 고시 · 행정규칙 · 시행 2019-05-26 · 공포 2019-05-20 · 일부개정

### 전문
1. 통계의 명칭         : 장애인고용패널조사 2. 통계작성기관의 명칭 : 한국장애인고용공단 3. 통계작성승인번호(작성승인일) : 제383003호(2007.06.27.) 4. 통계작성의 변경 연월일      : 2019.05.16. 5. 통계작성의 변경 내용과 사유ㅇ 통계조사표·결과표 : 조사항목 추가·삭제·변경![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=42205608)* 일부 변경은 보기 항목만 일부 조정되어 전체 항목 수는 변동 없음ㅇ 교육영역의 분류기준 : 한국표준교육분류 기준 적용
