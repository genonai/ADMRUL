# 통계작성의 변경승인 고시(초·중·고사교육비조사)
> 고시 · 행정규칙 · 시행 2018-03-18 · 공포 2018-03-12 · 일부개정

### 전문
1. 통계의 명칭 : 초·중·고사교육비조사 2. 통계작성기관의 명칭 : 통계청 3. 통계작성승인번호(작성승인일) : 제920011호(2007.06.01.) 4. 통계작성의 변경 연월일 : 2018. 03. 09. 5. 통계작성의 변경 내용과 사유 : 결과표 변경(54개표→63개표)(변경사유) 이용자협의체 결과 및 응답빈도 고려 결과표 개선
