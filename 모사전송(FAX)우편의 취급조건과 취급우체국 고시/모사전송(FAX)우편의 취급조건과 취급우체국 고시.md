# FAX(모사전송)우편의 취급우체국과 취급조건
> 고시 · 행정규칙 · 시행 2008-04-21 · 공포 2008-04-03 · 폐지제정

### 전문
1. 취급 조건가. 서비스 종류1) 1종 : 우체국의 팩시밀리를 이용하여 전송한 후 우체국의 팩시밀리로 수신하여 원형을 재생시켜 수취인에게 창구에서 바로 교부하는 서비스2) 2종 : 우체국의 팩시밀리를 이용하여 수취인의 팩시밀리로 직접 전송하는 서비스3) 3종 : 우체국 팩시밀리 이외의 팩시밀리를 이용하여 전송한 후 우체국 팩시밀리로 수신하여 원형을 재생시켜 수취인에게 창구에서 바로 교부하는 서비스나. 통신문 용지의 크기 : A4용지(210×297㎜)에 통신내용을 기록, 인쇄한 것으로 한다. 2. 취급우체국가. 우체국 : 전국우체국 (단, 군부대에 소재하는 우체국은 아래 지역만 취급 가능)![그림](https://www.law.go.kr/LSW/flDownload.do?flSeq=9799418)나. 우편취급국(종전 우편취급소) : 취급하지 않음 3. 시행일 : 2008. 4. 21
